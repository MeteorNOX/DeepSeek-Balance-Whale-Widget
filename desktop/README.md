# DSH 小鲸鱼余额挂件 —— 桌面常驻版

把 DeepSeek Harness 的网页挂件魔改成的 **Windows 桌面常驻挂件**：纯 WinForms + GDI+，零依赖（不需要 WebView2、不需要任何安装），双击即用，开机可自启。

## 文件

| 文件 | 说明 |
|---|---|
| `start-widget.vbs` | **双击这个启动**（无黑框后台运行） |
| `whale-widget.ps1` | 挂件本体（宿主 + 渲染 + 余额拉取 + 交互） |
| `DSniang02.png` | 鲸鱼气泡图，必须和上面两个文件同目录 |
| `widget-key.json` | 保存的 API Key（自动生成，别外传） |
| `widget-state.json` | 位置/大小/层级记忆（自动生成） |

## 操作

| 操作 | 效果 |
|---|---|
| 左键按住 | 按压 Q 弹（鲸鱼被捏扁，松手带过冲回弹） |
| 左键点击 | 手动刷新余额（未配 Key 时弹设置框） |
| 拖动 | 移动；靠边松手自动吸附（贴左缘时镜像翻转） |
| 滚轮 | 缩放 0.6–1.4 倍 |
| 右键 | 菜单：层级切换 / 放大缩小 / 刷新 / 自动刷新开关 / 设置 Key / 开机自启 / 退出 |
| 右键 → 自动刷新 | 余额每 5 秒自动拉取（默认开，勾选状态重启后记忆） |
| 右键 → 设置 API Key | 填 DeepSeek Key，保存后**动态验证**：成功显示「验证成功：¥xx.xx」（绿），失败显示「验证失败：HTTP 错误码」（红） |
| 触摸屏 | 单指操作全支持：按住捏/拖动/点击刷新（WM_TOUCH 合成鼠标消息） |

**层级三种**：置顶显示（默认，永远在最上）/ 正常层级 / 贴到桌面层（贴壁纸，像 Rainmeter）。

**Key 来源优先级**：环境变量 `DEEPSEEK_API_KEY` > 本机 `widget-key.json`。两者都无时，点挂件或菜单弹设置框。

## 开机自启

右键菜单里勾选「开机自启」，会在启动文件夹创建快捷方式；再点一次取消。

## 故障排查

- 改坏了想恢复默认：删除 `widget-state.json` 即可重置位置/大小。
- 报错会写 `widget-error.log`（同目录）。
- 换了文件夹位置后，开机自启需重新勾选一次（快捷方式指向旧路径）。

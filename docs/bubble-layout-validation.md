# #159：椭圆泡泡内容的验证与回滚

正常容纳的内容保留原排版与字号。每次渲染后，用 SVG 坐标核对各个可见内容块的四角；越出椭圆内部时才切换为内接的滚动阅读区。滚动区不会修改用户配置、截断原文或继续缩小字号，底部的 `↕` 提示可滚动。点阅读区不推进泡泡，点白色泡泡边缘仍按原规则继续；滚动时续用当前泡泡的停留时长。新场景从头显示，同场景的内容更新保留滚动位置。

## 自动检查

```sh
node --test tests/*.test.mjs
node tools/z-layer-audit.mjs assets/whale-widget.js
node --check assets/whale-widget.js
node tools/ci-audit.mjs --no-pack
node tools/ci-audit-selftest.mjs
node tools/check-dead-settings.mjs
```

单元测试执行实际客户端函数，验证整块四角（包括多行段落）、安全区、镜像、可访问性以及更新/换场景的滚动位置。无需浏览器或 DSH。

## 可选的真实浏览器验证

`tools/bubble-layout-browser.mjs` 启动仅绑定127.0.0.1随机端口的假宿主，使用仓库里的客户端与素材；所有接口响应都是测试数据，外部请求被拦截。它使用全新非持久浏览器上下文，结束时关闭浏览器和HTTP服务，不安装DSH，不访问现有浏览器profile，也不读写用户配置。

在已备好 Playwright 和浏览器的开发环境中：

```sh
node tools/bubble-layout-browser.mjs qa-output/check
```

可通过 `WHALE_QA_PLAYWRIGHT` 指定已有 Playwright 模块位置，通过 `WHALE_QA_BROWSER` 指定已有 Chrome/Edge/Chromium 可执行文件。两者都是可选的本机环境变量，仓库不包含个人路径，也未增加运行时依赖。没有这些工具时运行上面的单元测试即可，不要为此在用户电脑上安装DSH。

测试包括普通余额三行、独立三行、大字号多行段落、六行和长文本，各用0.8/1.5/2.5三种缩放及左右镜像，共30种组合。检查可见内容的几何边界、横向溢出、滚轮可用、点阅读区不关泡泡、滚到最后一句以及刷新布局后滚动位置不丢失。截图和JSON度量写到指定目录，默认 `qa-output/` 已被git忽略。

2026-10-05 验证环境：Windows，独立 headless Chrome 153.0.8010.53，859×608 CSS px，DPR=2。30种组合通过，页面脚本异常0；普通余额在6种缩放/镜像组合下保持原排版；长文末句可滚动到达。18个可直接对照原版的场景，实际字号均未改变。已查看正常、六行、多行段落与长文末尾截图。原版同一假宿主下能复现六行首末越出椭圆、长文上下穿出泡泡。Android WebView、iOS Safari、DSH Electron实际宿主仍需各自复验，这些浏览器结果不等于手机真机验证。

需要比较旧版时，可将旧客户端源码另存为本地验证文件，以 `WHALE_QA_SOURCE` 指向它，并设置 `WHALE_QA_BASELINE=1`：该模式仅收集旧版截图/度量，不要求旧版通过新几何断言。基线文件也放在忽略的 `qa-output/` 下即可。

## 生效与回滚

仅前端运行文件有变化。维护者在获准的测试副本部署该文件后硬刷新页面；宿主会按mtime重读资产，不必修改版本或运行时配置。

源码使用 `git revert <本提交号>` 回滚，再运行上面的检查；测试副本恢复上版前端文件后硬刷新。没有配置格式迁移、账本变更或素材变更，无需删除或还原用户配置。若更改SVG形状，需要同步更新椭圆安全区常量和几何回归测试。

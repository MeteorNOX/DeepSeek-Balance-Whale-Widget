# For-Codex 开发过程摘要

本文整理历次开发的最终决定与当前源码能力，不复制原始聊天、私人路径、账户或测试现场。v0.4.0 发布标签为 codex-v0.4.0；历史候选过程、自动测试结果和人工验收范围分别记述。

## 从原挂件到 Codex 适配

最初目标是在 Codex 桌面环境中保留小鲸鱼角色、声音、气泡和拖动交互，并读取当前 API 的余额。适配逐步形成独立 Electron 透明工具窗口、Windows 原生跟随、GUI 启动器、受限本地 IPC 与安装/回滚流程，没有向 Codex 安装文件注入前端。

API 余额从固定服务扩展为当前配置、兼容账单、兼容密钥额度和自定义 JSON 路径。后续审查加入端点与凭据归属检查、输入与资源预算、原子保存、损坏素材回退和可见错误，避免“界面说保存了，但磁盘没有成功”的情况。

## v0.2 阶段：计量与实际桌面使用

开发中明确了几个持续沿用的原则：

- 退出挂件只停止观察，不能当作停止 Codex 调用。
- 失败或取消仍可能产生计费；用量记录、任务状态与成功音效分别处理。
- 取消默认使用中性说明。仅明确识别高需求拥挤失败时使用“挤不进去...”文案。
- 设置页默认隐藏已有私密地址和本机路径；公开包不得携带个人配置和账本。
- 汇率是显示换算，账本保留原币种。自动检查、主动刷新与灰色感叹号说明分别承担更新和解释职责。

跨午夜观测基线、长期日汇总、待结算任务恢复和重复通知处理在这一过程中逐步完善。历史 v0.2 fixed 曾单独发布；早期试作中的版本号和趣味文案不代表现在的产品行为。

## v0.3 阶段：模式、界面与跨平台

产品增加 API/订阅模式和“概览 / 用量 / 设置”分页。订阅窗口显示官方快照，本机滚动 token 单独展示；不把百分比换算成固定“剩余 token”。

跟随 Codex 与独立桌面模式共用角色、声音和数据；增加可配置手感、原创合成短音与本地素材工坊。macOS 兼容工作来源于 [1llysviel 的 PR #128](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/pull/128)，保留平台探针、LaunchAgent、透明浮窗、Unix socket 和对应快捷键，不将该贡献重新署名为原创。

Windows 实际使用暴露了不同类型的“挂件消失”：窗口被隐藏、合成内容为空、绘制区域提前收缩和层级被压住。修复因此分别落在可见性协调、软件合成、动画区域生命周期与条件式层级纠正，而不是周期性重启挂件。透明区域的鼠标移动转发关闭，改由原生位置采样处理悬停，减少对宿主光标的干扰。

## 交互试作后的取舍

曾试作组件外点击关闭，实际需求澄清后主动撤回。挂件覆盖工作区，底层点击不能可靠表示用户已经阅读提示；主菜单、子面板和人物气泡也不应该被一个全局规则混为一体。

现在保持明确关闭、人物点击和提示自身超时；菜单按钮通过仅影响可见性的悬停范围保持可达，透明间隙继续穿透。详见 [空白点击决定](OUTSIDE-CLICK-DECISION.md)。撤回该试作没有撤回 macOS 支持、层级恢复或意外中断提示。

## 位置与九项基础修复

位置记忆问题来自“用户希望的位置”与“当前绘制的位置”混用：启动动画、临时缩窗和无关设置保存可能覆盖记忆。当前将位置意图独立持久化，在拖动/缩放完成后提交，重启恢复不采集动画中途坐标。

随后结合 DSH 参考说明做 Codex 源码审计，逐项处理完成音效组、设置初始化竞争、图片失败后的截止时间、旧编辑缓存、输入法组字、历史账户入口、小额精度和峰谷有效期。并行任务的消费报告又揭示了更根本的问题：同密钥区间扣费不能归属某个失败对话。账户总额与本轮估算因此分离；缺少依据的单轮金额在内部保留未知状态，界面保留 token 和任务状态，后续独立账户通知提供金额反馈。

## v0.4：逐项核对 issue 与实际使用反馈后的发布整理

审计没有把 DSH issue 标题直接当作 Codex 缺陷，也没有把上游“已修复”评论当作当前分支已经包含。先读正文与评论，再比对实际路径，必要时用真实函数和合成事件在内存复现。

本次重点落地账户额度筛选与逐窗口合并、气泡队列事务、通用安全区布局、拖动取消、严格配置读取、名称往返与裁剪音频生命周期。明确缩小范围：#108 仅修名称而未做共享台词池；#79 仅修共用取消分支；#135 没有 Mac 睡眠实测；#118 侧栏/输入框避让未实现。

## v0.4 的两次实际使用反馈

并行时只显示“单轮金额未知”虽然避免了错误归属，也失去了用户需要的账户消费反馈。最终把二者拆成独立信息：有效余额/累计用量采样带来“账户新增消耗”，不需要模型单价；每轮状态和 token 单独记录，有价格时才估算本轮金额。首次样本建立通知基准，后续新增按账户和计量上下文持久化；展示后确认，重复采样、多个任务结束和确认重试不会把同一增量再分配一遍。暂停提示期间保留一份待显示累计，而非排出长队。

连续点击反馈揭示了另一个跨层问题：按压动画缩小角色的当前 alpha，松手后一帧就关闭输入保护，而回弹仍在继续；放大角色的原生窗口区域也可能收缩过多。最终让人物点击判定、输入路由和原生窗口区域共享有限的稳定轮廓，同时保留透明像素穿透，取消/失焦/移远时释放。真实原生测试又发现浏览器计时器接收者约束，修复后纳入回归，避免只靠模拟器得出结论。

发布前再次运行当前源码的 341 项自动测试和 9 项独立隐私门禁，全部通过。同一运行实现先前通过 120 次角色边缘原生连击、18 次透明区对照与 5 组账户通知 Electron 端到端；这些专项本次未重跑。边缘点击零泄漏，透明区保持穿透。更早的 52 个通用布局场景和位置重启也只作为基线证据。

发布整理保留功能、来源和可回滚性，补齐 README、[issue 状态表](ISSUE-STATUS-0.4.md)、验收清单和公开材料。当前对外包名为 Codex-v0.4，程序版本 0.4.0，内部标识继续使用 api-balance-whale；发布标签 codex-v0.4.0。真实订阅账号、Mac、其它输入设备和长期稳定性未验证部分继续明确保留。

## 维护原则

仓库所有者和上游作者仍为 [MeteorNOX](https://github.com/MeteorNOX)，Codex 适配由协作者 [Yang-huai406](https://github.com/Yang-huai406) 维护。For-Codex 独立版本不替代 DSH 主线 Latest；后续发布应另核对标签，保留旧发布和兼容来源。

每次安装用私有回执关联备份，回滚恢复程序并保留新增设置、素材与账本。公开分发只包含可复核源码、文档、许可与必要素材；原始聊天、私人数据和运行现场不属于公开开发材料。

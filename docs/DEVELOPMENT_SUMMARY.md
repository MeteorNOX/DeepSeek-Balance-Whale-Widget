# v0.3(fixed) 开发摘要

本版保留 v0.3 的完整功能，并修复窗口显示、失败用量提示、气泡收起和菜单悬停。显示名称为 **v0.3(fixed)**，插件构建标识仍为 `0.3.0+codex.20260929173027`。先完成本地交付准备后，用户已明确授权本次上传 `For-Codex` 分支、新 tag 和 Release；授权不代表用户测试清单已全部通过。

## 基础功能与来源

从 fixed 基线继续维护，保留 B 版“概览 / 用量 / 设置”、角色与声音、气泡、资源管理、预警、预算、图表、高级接口、本地 JSON 工坊，以及跟随 Codex / 独立桌面模式。API 展示金额，订阅展示 token 与分开的 5 小时、每周额度窗口；切换展示模式不修改 Codex 登录或密钥。详细功能见 [B 版对照](DASHBOARD-B.md)。

保留 [macOS PR #128](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/pull/128) 的平台实现、来源链接及贡献者 [1llysviel](https://github.com/1llysviel) 署名。Codex 适配维护者为 [Yang-huai406](https://github.com/Yang-huai406)，仓库所有者仍为 [MeteorNOX](https://github.com/MeteorNOX)。Windows 原生窗口区域逻辑继续独立，不向 macOS 调用不支持的接口。

## 显示、层级与诊断

健康诊断与显示操作分离：短暂监督器心跳延迟不再被直接当作宿主消失。保留启动就绪、模式切换、窗口尺寸同步与迟到 IPC 的修复。

对已确认的 Windows 层级异常，先核验宿主、挂件、归属及前台状态，再有限调整挂件的普通窗口层级；不设置全局置顶，不改变焦点、位置或穿透。软件合成及关闭部分遮挡优化属于兼容措施，尚不能证明是全部偶发消失现象的唯一解法。

保留有上限的本机状态记录与 **Ctrl+Alt+Shift+F10** 诊断快捷键。诊断只读取窗口状态元数据，不抬升窗口、不强制恢复、不截图，也不记录聊天正文或凭据。详见 [显示与诊断说明](VISIBILITY-CANDIDATE.md)。

## 气泡与菜单交互

气泡原本在收起开始时就被移出 Windows 原生绘制区域，但子元素仍在延迟淡出，造成直线裁边。现在按气泡、菜单和按钮的真实动画生命周期保留绘制边界，动画结束或取消后重新计算；旧关闭回调不会裁走刚重新打开的内容。

绘制和点击分开处理。关闭动画可以完整呈现，正在退出的控件停止接受点击，透明范围继续穿透。菜单按钮首次由人物不透明像素唤出；出现后，人物至按钮之间的有限范围保持悬停，离开后短暂延迟隐藏，重新进入则取消隐藏。菜单打开时保留按钮，“隐藏菜单按钮”偏好优先。悬停保留范围不扩大点击命中。详见 [绘制生命周期与悬停修复](SURFACE-LIFECYCLE-FIX.md)。

## 空白点击的最终选择

曾评估并实现过全局空白点击关闭，随后主动撤回。当前不监听其他软件中的点击来统一关闭挂件菜单、人物气泡或账户卡片；保留各控件原有关闭入口、人物点击交互及已有超时规则。

[Issue #177](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/issues/177) 的建议有合理的使用场景，但本挂件覆盖在用户正在操作的软件上，宿主中的正常点击不宜被一概解释为“已经看完提示”。决定的详细理由、二级菜单范围和穿透约束见 [空白点击设计决定](OUTSIDE-CLICK-DECISION.md)。这是本版的产品选择，不代表跨平台无法实现，也不评价提议者的实现质量。

## 失败用量与隐私

明确失败、中断终态以及被下一轮替代的未结束轮次，仍按已有“每轮消耗”设置显示中性用量提示。重连中的流错误和明确将重试的错误不提前结算；历史恢复不重复弹出。取消保持中性，普通失败不播放成功或拥挤音效；未知或待记账金额不写成零。API 观测差额不等于精确逐请求账单，订阅模式的本机 token 不等于官方剩余额度。

已有私密配置不回显，未填写时保留原值。分发包排除个人回执、运行数据、聊天媒体及本机配置，保留公开版权、贡献者署名和第三方许可。

# Codex-v0.4(fixed)：已知限制与待验证事项

适用包名 `Codex-v0.4(fixed)`，内部版本 `0.4.1`、构建 `auto-probe-fixed-20261005`。发行标签 `codex-v0.4.0(fixed)`。本文记录仍存在的边界，不把历史基线或一次本机成功当作全部验收。

## 余额接口与配置

| 项目 | 当前边界 |
| --- | --- |
| 自动识别范围 | 有来源依据的若干协议族、路径别名和单位元数据。十三项注册记录不是十三个品牌分别实测，也不是每次全部请求 |
| 未知字段、单位或范围 | 强契约才自动生效；有完整假设的候选需用户对照账单核对。无法形成可靠规则时仍需高级配置，不把未知当零或现金 |
| 管理接口权限 | 普通推理 key 不默认试探管理接口；OpenRouter 账户 credits 等需要明确的专用认证。某一余额端点拒绝 key，不足以证明该 key 无法调用模型 |
| OneHub 与兼容账单 | 相同响应形状可能表示账户额度或 key 额度，`*_usd` 名字也不总能证明实际币种。缺少范围依据时保留候选，不能宣称所有兼容账单已自动确认 |
| 原始 quota | `token_usage` 与 `credit_summary` 的 `total_*` 不是天然货币。自动使用有效元数据；显式规则先应用基础配额换算再乘系数，不能重复除默认单位 |
| 复杂认证与请求 | 已支持 POST JSON 及受限的头、参数、环境引用；任意网页登录、表达式执行、把秘密直接持久化到 body 等未提供。#190 为部分覆盖，不是仍然只支持 GET |
| 配置来源 | follow 只反映实际读取到的配置及 profile，不含未读取的 CLI 临时覆盖；固定连接也不保证等于当前聊天采用的推理服务 |
| 旧覆盖迁移 | 无绑定的旧地址与 key 环境引用需要明确核对同一来源；无关设置保存不会悄悄授权迁移。回滚后旧程序可能重新采用旧根设置，须核对实际连接 |
| 读取和秘密环境变量 | 环境引用必须在运行挂件的进程环境中可用。程序不替用户创建凭据或修复站点权限，不在普通预览返回原始秘密 |
| 请求与缓存 | 单请求、整轮时间和请求数量有上限。超时、限流或请求预算耗尽时可能尚未找到可用接口；限流退避不能靠重新检测绕过 |
| 端点变化 | 命中/候选只刷新对应计划，到期、失效或手动重探测后再识别。服务商改路径、响应或单位后可能需要重新确认；不跟随任意重定向转发认证 |

当前已确认本机真实查询能正常取得候选结果（candidate），但不公开相关地址或配置；这不是所有服务、认证方式与币种的实测清单。来源及具体协议见 [公开来源表](BALANCE-PROTOCOL-SOURCES.md)，操作见 [自动检测说明](AUTO-PROBE-FIXED.md)。

## 金额、历史与通知

| 项目 | 当前边界 |
| --- | --- |
| 账户新增不等于单轮账单 | 差额可能包含并行聊天、其他设备或服务商延迟入账；不能全部归属一个对话。按模型价格得到的本轮估算是另一项指标 |
| 新基准 | 首次有效样本、账户或计量口径变化先建立基准，不追报此前消费。升级后暂时没有新增金额气泡不代表过去免费 |
| 历史不重算 | 不自动清洗旧错误口径或回填旧账单，不恢复已经被旧版本删除的记录。原币种、不同匿名账户不擅自合并 |
| **退款净额未实现** | 目前只累加正向消费差额。余额回升或累计用量回退不冲减旧累计，统计可能高于退款后的净支出 |
| 同时充值与消费 | 只有余额快照时只能看到净变化，不能拆解充值、退款和消费的每笔流水 |
| 中断与跨日 | 保留基线并在恢复时处理差额；不能精确分配中断期间每天的消费，没有账单导入或人工补录。#184 未全面完成 |
| 更新延迟 | 后台定时、任务事件及用户刷新都可能触发采样，还受服务商入账速度和退避影响；不保证每轮立刻显示金额 |
| 暂停展示 | 关闭提示、页面隐藏或切到订阅模式可能暂停 API 通知并合并累计；恢复时出现一笔合并金额不代表刚刚一次调用花了这么多 |
| 通知去重 | 正常存储下抑制重复；删除/损坏本地记录、存储失败与崩溃组合可能丢失通知记忆，不承诺跨故障绝对一次展示 |
| 失败与取消 | 已发出的请求仍可能收费，零 token 记录不能独立证明免费。未知金额保持未知，不能补成零 |
| 汇率与峰谷 | 汇率仅供显示参考；服务商规则及有效期需匹配，不用显示规则改写原账单 |

## 订阅、桌面与平台

- 订阅额度依赖会话提供的快照，可能缺失、过期或因扫描资源上限而不完整；本机 token 不是官方固定剩余额度。真实订阅账户切换链路仍需对应账号验收。
- 本轮 Windows/Electron 合成场景不替代其它鼠标、触控板、触屏、多屏、DPI、GPU、高负载与长期稳定性测试。#121 保留已验证修复，不声称全部消失原因根治。
- macOS PR #128 的兼容代码与来源保留；Apple Silicon/Intel、Spaces、全屏、多屏及睡眠唤醒未在本轮实机全验收。Mac 脚本的桌面组件/LaunchAgent 安装不等于完整技能/MCP 自动注册。
- #135 的音频生命周期修复不等于 Mac 睡眠断言已通过。#187 的故障设备首音裁切仍待实机，未加入专用前导唤醒音；#197 双重音效原根因尚未明确复现。
- 安全区排版会缩小过长文字；极小挂件或复杂素材仍可能不适合长文阅读。本轮七个布局样本不代表任意内容组合。
- 独立桌面模式是透明浮窗，不是壁纸层。#177 全局空白点击关闭主动不采用；底层工作点击不会统一清空未读提示。

## 安装、回滚与反馈

普通安装仍需满足 Node.js 24+、npm 和可用的 Codex 插件注册入口；Electron 初次下载受网络与代理影响。脚本策略、目录和计划任务权限问题按具体错误处理，不把未通过检查称为安装成功。Python/Pillow 是开发原生 QA 的依赖，不是普通使用必须安装的组件。

初期连接版与 fixed 内部版本同为 `0.4.1`，应同时核对构建标识和本次安装回执。回滚恢复对应程序与启动配置，保留新增设置、素材和账本；不凭版本号猜备份，也不通过删除账本回滚。Mac 使用其对应流程，见 [macOS 说明](MACOS.md)。

本轮验证记录为 **482 项自动测试、9 项隐私门禁、6 组 Electron 流程、7 个布局样本、8 张截图**；这些是当前已列场景的证据。旧 341 项测试、120 次边缘连击、18 次透明对照和 52 个布局场景保留为历史基线，不称本轮重跑，也不叠加成总验收数量。

反馈请提供公开版本/build、操作系统、设备和显示环境、复现步骤、预期与实际结果；金额问题说明是账户新增、累计、key 额度还是单轮估算。不要上传真实密钥、完整 provider 配置、个人路径、原始聊天、账本、安装回执或未脱敏截图。公开材料只保留必要的复现与来源，不含原始私有现场。

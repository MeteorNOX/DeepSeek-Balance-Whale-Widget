# v0.4 用户验收清单

**用途：For-Codex v0.4.0 发布版的用户验收与回归。** 记录通过、失败或未测试；没有订阅账号或 Mac 设备的项目标记未测试，不用模拟成功代替。

## 安装与回滚准备

- [ ] 校验 `Codex-v0.4.zip` 与附带 SHA-256 一致，完整解压。
- [ ] 确认 Node.js 24+、npm、支持插件注册的 Codex CLI 及首次下载 Electron 的网络可用。
- [ ] 运行安装预检；已有安装时保留安装器生成的私有备份和回执。
- [ ] 安装后检查状态版本为 `0.4.0`。新建聊天可加载新版技能；不要把重开聊天误当作桌面服务重启。
- [ ] 回滚预检能找到本次安装回执；先记下已有设置与账本的大致状态，方便比较。

在包目录运行以下只读检查：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-package.ps1 -CheckOnly
node scripts/control.mjs status
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\rollback-package.ps1 -CheckOnly
```

## 日常操作

| 检查 | 预期 |
| --- | --- |
| 打开、最小化、恢复 Codex | 跟随模式按宿主可见性工作；恢复后能看到角色。 |
| 窗口缩小再放大，改音量 | 暂时受限的绘制位置不覆盖原记忆。 |
| 拖到边角或中间，缩放后正常退出再打开 | 同样窗口条件下回到记忆位置；无启动动画导致的跳位。 |
| 在无害背景上连续点角色中心与边缘 | 角色持续响应，背后控件不被误点；离开到真正透明区，底层仍正常收到点击。 |
| 正常拖动松手 | 新位置保存；点击未拖动仍按原规则执行。 |
| 拖动中切走焦点 | 取消未完成手势，不跳到零坐标，不覆盖之前记忆。 |
| 输入框移入移出、拖选文字 | 透明区域不夺取宿主输入或异常切换光标。 |
| 从角色经过透明缝隙移向菜单 | 按钮可达；缝隙本身不拦截底层点击。 |
| API/订阅和桌面/跟随切换 | 界面状态一致；独立桌面模式下最小化 Codex 后仍可显示挂件。 |
| 关闭气泡再快速打开 | 主泡与尾泡完整淡出，不被旧回调或原生窗口区域裁切。 |

若再次看不到挂件，先保存现场操作时间与步骤，再尝试托盘恢复或快捷键。短期通过仍不替代长期稳定性观察。

## 金额、额度与历史

- [ ] API 模式余额单位与服务商接口文档一致；设置留空不会覆盖已有私密字段。
- [ ] 不配置模型价格时，完成首次有效采样后，日常新增扣费仍出现“账户新增消耗”金额气泡；首次采样不会追报旧历史。
- [ ] 两个任务并行或一个失败时，账户新增金额不被标成失败对话的单轮费用；单轮 token/状态另行显示。
- [ ] 同一余额重复刷新、两个任务相继结束，不重复报告同笔新增；后续真正新增只显示新的增量。
- [ ] 接受后台通常约 60 秒采样和服务商延迟入账；必要时手动刷新，不因当轮结束后暂未弹金额就判断免费。
- [ ] 关闭消费提示后再打开，看到关闭期间的累计而不是一长串逐轮提示；切到订阅模式再回来，API 待显示增量保留。
- [ ] 已配置完整模型价格时，本轮金额标明估算；估算不会重复累加到账户合计。
- [ ] 退款、充值或服务商累计值回退时，将差异记为账本限制，不把挂件数字当作退款后净额。
- [ ] 如果自然产生小额用量，显示仍为两位小数，小额提示可见，后续累计不会漏掉增量。
- [ ] 历史账户入口列出匿名账户与币种；选旧账本可看记录，不需要恢复失效密钥。
- [ ] 真实订阅登录产生新快照后，5 小时与周窗口各自显示重置时间。缺失/过期状态不冒充新鲜数据。
- [ ] 订阅模式中的本轮 token 与本机统计有来源说明；不出现凭空换算的“剩余 token”。
- [ ] 主动刷新汇率后说明可展开；网络失败保留合理状态，不将账本原币种改写。

不必为了测试人为制造付费失败请求。类型混合、部分额度、极小增量、写盘失败等边界由隔离的自动测试覆盖；人工验收关注实际使用表现。

## 气泡、编辑器与音频

- [ ] 在正常及较小窗口、不同角色大小和左右翻转下，检查金额、预算提醒、多行文本及图片气泡；文字完整且位于白色区域内。
- [ ] 气泡保持打开时调整窗口或大小，内容不丢失；超长文案允许缩小，实际阅读仍应清楚。
- [ ] 气泡切换遇到素材加载失败后，后续提示仍能继续；不要删除真实素材来制造失败。
- [ ] 自动关闭时长生效；最小化超过时长再恢复，过期气泡按规则收起，常驻提醒不被误收。
- [ ] 调整声音、选择完整音效组并试听，检查完整片段顺序及音量；总音量为 0 时静音。
- [ ] 打开并关闭音频裁剪面板后，旧试听不继续播放；重新打开仍能试听。
- [ ] 声音面板取消不保存；设置保存错误会提示，重开后不会悄悄恢复为默认值。
- [ ] 给普通屏和随机候选配置名称，保存重开仍保留；编辑器旧窗口不能静默覆盖较新配置。
- [ ] 使用输入法组字时 Enter/Esc 只处理组字，不误保存或关闭编辑器。

## 回滚验收

需要回滚本次安装时，在保留回执的前提下运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\rollback-package.ps1
```

- [ ] 有旧安装时恢复旧版本和原启动任务；没有旧安装时撤回本次安装。
- [ ] 最新设置、素材和账本保留，安装器未以旧备份覆盖新消费记录。
- [ ] 未找到有效回执时明确失败，不猜测备份路径。
- [ ] 私有回执和回滚备份保留在本机，不随反馈上传。

## 开发验证与结果记录

本次发布源码重新运行 341 项自动测试与 9 项独立隐私门禁，全部通过。同一运行实现先前在专用无害宿主完成 6 组共 120 次 Windows 边缘连击（零误点）、18 次透明对照（正常穿透），以及 5 组账户通知端到端；本次未重复这些原生/端到端专项。

52 个通用气泡布局场景及位置重启结果来自较早相关实现的验证，本版不将其计为新重跑。当前成品的版本、依赖、公开文件、哈希和解压核验以发行目录的 `verification-report.json` / `release-manifest.json` 为准。

源码包可运行 `npm test`、`node scripts/check-package.mjs`，隐私拒绝门禁运行 `python -B tests/release-privacy-test.py`。本机原生开发 QA 还使用 64 位 Python/Pillow；普通安装不需要这些测试依赖。原生鼠标测试必须使用专用无害宿主及隔离数据，不向日常工作窗口发送自动点击。不要把存在旧断言的历史视觉脚本当作本版自动验收入口；执行真实桌面专项时使用本版明确提供的 fixture，输出放在独立测试目录。

反馈建议格式：版本、系统、检查项、通过/失败/未测试、复现步骤。请只提交必要的脱敏信息，并逐项记录通过、失败或未测试。

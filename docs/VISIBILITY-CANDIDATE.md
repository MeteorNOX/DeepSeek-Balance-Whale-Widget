# v0.3 Windows 显示候选修复

本次针对“Codex 内小鲸鱼偶发不可见，操作软件外部后又出现”。保留 v0.3 功能、Windows 鼠标移动不转发的光标修复，以及 [macOS PR #128](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/pull/128) 的兼容代码与署名。

## 改动

- 仅小鲸鱼的 Windows Electron 进程关闭 Chromium 原生窗口遮挡计算和遮挡后台优化；沿用软件合成。Codex 本体不受影响。这是候选兼容措施，尚不能确定每次消失的唯一原因。
- Windows 监督器提供只读窗口元数据：原生区域、DWM 隐匿状态、真实归属、层级、前台关系与位置。不会通过抬升、切焦点或重绘来采样。
- 现场记录与独立 Windows 枚举确认过挂件被排在 Codex 下方。有条件地纠正这种层级异常：核验两个进程、归属、宿主前台及可见状态后，只调整挂件普通层级，保留焦点、位置、区域和穿透，不设全局置顶。每次异常最多三次尝试；已经位于宿主上方时不操作。实测从下方恢复到上方，焦点与几何不变，重复调用无操作。
- 最近约两分钟的状态保留在有上限的本机记录中，最多每十秒写入一次。**Ctrl+Alt+Shift+F10** 静默保存当前报告，最多轮替保留三份。快捷键不显示窗口、不恢复挂件、不截图、不记录聊天正文或凭据。
- 修正压力测试：测试窗口不再置顶，采样前不再抬升；第一份异常屏幕样本先保存，随后才允许进一步排查。单纯切换前台不应造成挂件隐藏和重显。

## 复现和反馈

出现消失时保持 Codex 在原位置，直接按一次 **Ctrl+Alt+Shift+F10**，然后在聊天中报告时间即可。没有弹窗是正常的。报告位于插件数据目录中的 `visibility-report-1.json` 至 `visibility-report-3.json`，后续切换窗口不会改写刚保存的报告，除非再次按快捷键轮替覆盖。`status` 中的 `diagnostics.shortcutRegistered` 必须为 `true`；冲突或注册失败时仍有 `visibility-observation.json`。

元数据“可见”不等于屏幕像素已经呈现，报告不会据此自动宣称正常。报告不包含截图，必要时仍须进一步定位合成问题。

## 验证范围

单元测试及真实 Electron 界面回归覆盖气泡收起、首次点击、外部拖动穿透、桌面/跟随切换。最终数量见交付验收记录。新的非置顶屏幕像素测试首次运行被其他窗口持续遮挡，返回未能判定；不能把它称为通过。长期偶发消失与 macOS 实机仍待验证。

## 回滚

完整安装前由现有安装器备份旧插件、设置和数据，并生成本次私有回执。使用该回执对应的 `rollback-package.ps1 -Receipt <installation.json>`；先加 `-CheckOnly` 检查，再执行回滚。保留回滚时最新用户数据。安装成功后新建 Codex 聊天可加载新版技能和工具，挂件由安装器自动重启。

## 空白点击功能已撤回

按用户决定撤回新增的空白点击关闭功能，移除 Windows/macOS 全局点击监听、消息转发与菜单自动关闭逻辑。菜单与气泡恢复该功能加入前的交互方式。挂件层级修复、诊断快捷键和意外停止后的消耗提示保留。

随后针对气泡收起裁边和菜单按钮悬停消失，加入[绘制生命周期与悬停修复](SURFACE-LIFECYCLE-FIX.md)。这两项修复保持透明区域穿透，不重新引入全局空白点击关闭。

## 意外停止仍显示消耗

普通失败此前被服务和界面同时过滤，缺少后续完成记录的错误也可能一直等待。现在明确的轮次错误（未声明重试）、失败/中断终态和被下一轮替代的未结束轮次会结算并显示中性用量提示。重连中的 `stream_error` 和明确会重试的错误不提前结算；历史恢复不重复弹出，取消仍覆盖之前的拥挤失败。

提示沿用“每轮消耗”开关，金额未知或待记账保留该状态及已观测 token。API 模式显示对应金额/用量，订阅模式只显示本机 token；普通失败不播放成功或拥挤音效，不使用失败趣味文案。

已有计划任务无法修改但仍可运行时，可在核验任务、运行时及目标路径一致后使用安装器 `-KeepExistingTask`。它只停止本插件监督器、更新代码并重启原任务；回滚同样复用原任务，不改变任务注册或权限。

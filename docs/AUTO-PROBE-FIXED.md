# Codex-v0.4(fixed)：自动检测与直接确认

对外版本和文件名为 `Codex-v0.4(fixed)`；内部版本保持 `0.4.1`，构建标识为 `auto-probe-fixed-20261005`。本轮是本地修复，未更新远端 Release 或标签。

## 为什么上一版一直待确认

连接查询本身可以成功，但上一版把普通第三方的自动检测结果一律标成未确认，普通预览也没有直接采用候选的入口。此次将协议匹配、单位依据和人工确认分开：证据完整的协议自动生效；有可核对假设的候选提供“确认并使用”；未知字段或缺少可用单位时保留高级配置入口。

兼容账单字段名并不足以证明账户现金。公开 OneAPI/NewAPI/Veloera 实现用 100000000 表示无限密钥额度，部分部署按显示设置返回原始 quota 或不同币种。NewAPI `object=token_usage` 下的 total_* 是原始配额；`credit_summary` 的 total_used=0 是占位值，不能当累计消费。相关来源和注册表见 [公开协议依据](BALANCE-PROTOCOL-SOURCES.md)。

## 普通使用流程

1. 打开 API 余额设置，点击“重新检测接口”。无需先新建连接或填写 JSON。
2. 显示“已识别并验证”时可直接使用，后续正常刷新复用命中接口。
3. 显示候选时，阅读它的币种、换算和额度范围假设，对照服务商页面。正确后点击“确认并使用”，程序保存与当前来源绑定的连接并重新加载。
4. 没有确认按钮时，当前证据不足以形成可靠的金额规则；按服务商说明使用折叠的高级配置。缺少余额接口或权限时如实提示，不把它当零余额。

例如兼容账单可以按 USD 总额度、美分累计用量提供候选，但服务商没有额外单位说明时不能静默当作已验证账户余额。若实际币种或倍率不同，应通过高级连接设置正确规则，而非盲目确认。

“确认并使用”只接受服务端签发的临时候选标识，绑定本次草稿、当前设置和凭据来源，五分钟过期且只能使用一次。来源变化、另一次预览或旧窗口的迟到结果均不能复用它。不复制密钥到设置，也不顺带保存未提交的模型价格。预览不写账本；正式查询按新计量基准开始。

## 探测与缓存

- 按已核实的协议和同源路径依次尝试，支持新旧尾斜杠拼写及代理前缀，拒绝任意重定向。
- 注册表有 13 项来源记录，包含配对的账单请求、单位元数据和需专用凭据的接口；不是 13 个独立品牌，也不会每次无条件发送全部请求。普通推理密钥不用于试探管理接口。
- 默认单请求最多约 3 秒，整轮约 15 秒、最多 16 次 HTTP 请求。界面显示实际请求次数；配对请求与匿名元数据也计数。
- 命中及可确认候选缓存请求计划，后续刷新只查该计划。计划最长十分钟后复核，站点单位元数据约六十秒复核；不缓存敏感响应体或候选金额。
- 全部明确不匹配的结果短暂缓存两分钟；“重新检测接口”可以跳过识别缓存。网络故障、权限错误、服务端异常和未完成探测不缓存成“不支持”。
- 限流会暂停探测，遵守有上限的 Retry-After 退避；普通刷新和设置预览共用退避状态，重新检测不能绕过它。

已实现协议族包括原生 OneAPI/NewAPI 类配额、兼容账单、DeepSeek、OpenRouter 密钥额度、LiteLLM 密钥预算、SiliconFlow 官方区域余额。OpenRouter 账户 credits 需要管理凭据，仅在明确配置专用认证时启用。具体域名或返回字段不符合这些契约时仍可自定义，不宣称已实测全部中转站。

## 金额与历史

自动命中必须通过字段类型、单位来源、额度范围和不限额语义检查。原生 quota 验证安全整数及加总关系，按已证实的 quota_per_unit 换算；显式 NewAPI 规则也识别这些原始对象。不限额不显示巨额有限金额，credit_summary 的占位使用量不参与差分。

协议、单位、计数器或账户变化时建立新基准，避免把两个指标相减成消费。既有历史不凭猜测重算；API 账户、密钥额度和本机 token 分别展示。自定义表达式、复杂网页登录或服务商不提供的账单不能凭自动探测构造出来。

## 验证与回滚

验证普通检测→候选确认→保存重载；修改来源后旧候选应失效；自动可信接口不要求填写 JSON；多次刷新不重跑整套探测；全部明确不匹配显示无法查询，网络/鉴权/限流给出相应提示。设置和金额气泡继续使用已验证的滚动与安全区布局。

安装器会生成本次私有回执和备份。由于前后内部版本同为 0.4.1，回滚时同时核对备份构建标识：本次之前为 provider-connections-20261005；当前为 auto-probe-fixed-20261005。使用本次安装绑定的回执回滚，保留新增账本与素材；不要仅凭版本号猜测备份。当前测试结果见交付目录的 verification-report.json；Mac 和其它真实服务仍需对应环境验证。

# v0.4 已知限制与待验证事项

**适用于 For-Codex v0.4.0 发布版（codex-v0.4.0）。** 以下列出已知限制和未验证范围。

## 安装条件

- 普通安装需要 Node.js 24+、npm，以及支持插件注册命令的 Codex CLI；安装器会检查可用入口。仅有不支持插件命令的旧客户端不足以完成注册。
- 首次 Electron 下载受网络或代理环境影响；按安装器返回的下载错误检查网络后重试，完整离线运行时未随 ZIP 提供。
- Windows 的脚本策略、目录权限或计划任务权限可能阻止安装。按具体报错处理所需权限，不建议为此全局降低执行策略；未通过验证不应视为安装成功。
- macOS 脚本只安装桌面组件与 LaunchAgent，完整技能/MCP 注册未自动完成，也未在本轮 Mac 硬件验收。
- 64 位 Python 与 Pillow 用于原生开发测试，是开发 QA 依赖，**普通用户安装不需要**。

## 账户通知与计费

| 项目 | 当前边界 |
| --- | --- |
| 账户新增不等于单轮账单 | 无需模型单价即可根据有效采样显示新增金额；可能包含并行聊天、其他设备或延迟入账，不能归属某个对话。 |
| 首次通知基准 | 第一次有效样本建立通知基准，不追报此前历史消费。升级后暂时没有新金额气泡不表示历史未消费。 |
| 采样延迟 | 后台通常约 60 秒查询，任务起止/用户刷新也查询；还取决于服务商何时入账，不保证每轮立即出金额。 |
| 开关与模式 | 关闭消费/气泡提示、页面隐藏或切到订阅模式会暂停 API 通知展示，新增合并累计；恢复后可能先看到暂停期间的合并金额。 |
| 去重的存储边界 | 正常存储下，显示标识和后端确认共同抑制重播。删除/损坏账本或本地显示记录，或存储失败与崩溃同时发生，可能失去通知记忆；不承诺跨故障的绝对一次展示。显示次数不等于服务商扣款次数。 |
| 失败与取消 | 已发生请求仍可能收费，零 token 记录也不能单独证明免费。单轮未确认费用保留 token，账户新增仍独立提示。 |
| 退款后净额尚未实现 | 当前只累加正向消费差额。服务商累计用量回退、余额回升时不会冲减旧累计，因此统计可能高于退款后的净支出；此项尚未修复为净额账本。 |
| 余额混合变化 | 只有余额时，充值/退款与消费同时发生只能看到净变化，无法还原各笔流水；有效累计消费接口通常更合适，但仍需确认其退款语义。 |
| 跨日及中断 | 保留基线并在恢复日计入差额，无法精确分摊每天；没有账单导入/人工补录。#184 不列为全面完成。 |
| 历史与账户 | 日汇总保留，明细及页面条数有上限；旧版本已删除的数据无法恢复。不同匿名账户和币种不擅自相加。 |

## 额度、平台与交互

- 订阅额度依赖本机会话提供快照，可能缺失或过期；扫描有资源上限，超限标不完整。没有固定“剩余 token”；本机 token 可能包含多账号/提供商，不能当作当前订阅剩余额度。
- 切换订阅账号后的完整链路仍需真实账号验收。合成额度回放通过不等于官方账户端到端测试。
- 120 次 Windows 边缘连击和 18 次透明对照已通过，但只覆盖公开列出的六组组合。其它鼠标、触控板、触屏、高负载、多屏和不同 DPI 仍需实测。
- #121 涉及多种消失原因。当前保留本机验证的合成、可见性、绘制区域和层级修复，长期跨设备稳定性仍需观察。
- macOS PR #128 代码和来源保留，但 Apple Silicon/Intel、Spaces、全屏、多屏和睡眠唤醒没有本轮实机验收。Mac 安装脚本只完成桌面组件与 LaunchAgent，不自动注册 Codex 技能/MCP。
- #135 已改进音频上下文生命周期，不宣称实测消除所有 Mac 睡眠断言。#187 音频设备休眠吞首音仍需故障硬件验证，未加入专门前导音。
- #197 双重音效报告尚未复现为明确当前缺陷；需区分重复实例、事件、素材本身和设备行为。
- 通用气泡布局采用安全区缩放，极长文案可能太小，不适合作为长文阅读器；字体和素材差异仍可反馈。
- 桌面模式是独立透明浮窗，不是壁纸层。#177 全局空白点击关闭为主动不采用，保留明确关闭、人物点击及提示自身超时。
- 汇率只是显示参考，周末可能沿用工作日数据；DeepSeek 峰谷仅在适用端点和规则有效期内展示，不修改账单。

## 如何报告问题

提供版本、操作系统、显示器/DPI、输入设备、复现步骤、预期与实际结果。金额问题区分账户新增、账户累计与本轮估算；连击问题说明点击位置、大小、方向和大致速度。

不要公开密钥、供应商私人配置、账号、完整会话、未经处理的截图、账本、安装回执或 `runtime.json`。先保存本地诊断副本，再筛选必要的脱敏信息。本清单没有向上游发评论、关闭 issue 或创建 PR。

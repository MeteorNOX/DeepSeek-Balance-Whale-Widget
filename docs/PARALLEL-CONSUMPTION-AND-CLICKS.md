# v0.4.0：并行消费反馈与连击保护

版本为 0.4.0，发布标签 `codex-v0.4.0`。`candidate-20261005` 保留为已测试运行构建标识；未验证的硬件和长期使用场景继续见已知问题。

## 并行任务也显示新增消费

账户余额和今日已观测消费照常刷新。每次有效余额／累计用量采样发现新增扣费时，按账户、币种与计量方式累计到独立通知批次，显示“账户新增消耗”。它不要求配置模型价格，也不归属某个对话。

同一笔增量只进入一个批次，多个任务结束不会各自报告整段余额差额。批次在实际呈现后确认；丢失确认时重试，已显示标识用于抑制重播。后台只有一个已发行批次和一个待发行累计，隐藏或关闭提示时不形成无限长队列。重新启用后显示未确认累计。

首次升级建立通知基准，不将历史总额一次性弹出。切账户、币种或计量方式隔离上下文。缓存、失败、过期或乱序采样不产生重复通知；延迟入账在后续有效采样中报告。既有后台余额采样约每60秒，任务开始、结束及用户刷新也会触发采样。

单轮提示继续记录状态和 token；有有效价格时另列估算，未能单独确认费用时显示“本轮用量已记录”和 token，不用醒目的“金额未知”取代消费反馈。账户新增消费本身不播放任务成功音，不应被当作某个失败对话的账单。

内部精确累计，展示两位小数；非零小额保留简短提示。仅有余额时仍是净变化观测，无法从充值、退款和消费混合中恢复完整流水；实际账单以服务商为准。

## 连续点击不落到宿主

角色按压和回弹会改变其当前透明像素。旧实现松手后一帧就解除输入保护，而回弹需要更长时间，放大角色边缘还可能被原生窗口区域裁掉。

本修订让鲸鱼本身的命中判断、输入穿透路由和原生窗口区域共用有限的稳定交互几何。保护覆盖已接受按压及回弹，随位置、缩放和镜像变化；取消、失焦、移远、换角色或切模式释放。不会扩成全屏透明遮挡层。原生按键采样也不能用过期状态覆盖刚完成的鼠标操作。

验证使用独立无害宿主窗口和真实 Windows SendInput：多尺寸、镜像和短间隔连击，并对照透明区域应继续穿透。测试只说明已覆盖矩阵，其他输入设备、多屏和高负载仍可反馈。

## 验收重点

1. 不配置模型价格，同时运行两个任务：观察账户新增消费仍有金额，单轮 token 单独显示。
2. 同一余额重复刷新，或两个任务相继结束，不应重复报告同笔新增扣费；随后新扣费只增加新批次。
3. 关闭提示再打开，查看累计提示与后续新增提示；切换账户不显示上个账户的迟到响应。
4. 连续点击人物上沿／边缘，检查角色响应且背后控件不被误触；移到真正透明区域，底层应正常接收。
5. 拖动、取消、缩放、换角色及最小化恢复继续保持此前行为。

回滚依旧使用本次安装生成的私有回执，保留新账本记录。旧程序不理解新增通知字段时仍能读取原账本字段；本版不修改 Codex 模型配置。发布到 For-Codex 的操作与本机安装、回滚分开处理。

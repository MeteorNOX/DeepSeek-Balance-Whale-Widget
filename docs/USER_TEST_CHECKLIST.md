## 安装、升级与回滚

- [ ] Windows“安装插件.cmd”或 Mac 安装入口能够运行，不依赖维护者本机路径。
- [ ] 首次获取 Electron 的联网要求和错误提示清楚；安装后确认实际运行构建正确、渲染器就绪。
- [ ] 升级保留自己的设置、素材、账本和显示模式。
- [ ] 安装器生成本次私有备份与回执；回滚预检能找到对应备份。
- [ ] 如需实际回滚，使用本次回执完成并核验；回滚后最新用户数据仍保留。

## 气泡收起与菜单按钮（本次重点）

- [ ] 人物气泡正常展开，关闭时主气泡、文字和尾部小泡依序完整淡出，没有水平或垂直直线裁边。
- [ ] 手动关闭、已有自动超时、快速关闭再打开均正常；旧动画结束不会裁掉新打开的气泡。
- [ ] 菜单和按钮淡出正常，已经关闭的区域不会吞掉底层软件点击。
- [ ] 从人物头部缓慢移向右上菜单按钮，在透明缝隙短暂停留后仍能点击按钮。
- [ ] 快速移向按钮、人物左右翻转后重复操作，按钮均可稳定到达。
- [ ] 菜单打开时按钮保持可见；离开人物与按钮范围后符合延迟隐藏规则；隐藏按钮偏好仍优先。
- [ ] 人物到按钮间的透明范围仍可点击到底层软件，不成为额外的挂件点击区。

## 空白点击的预期行为

本版主动撤回全局空白点击关闭，详见 [设计决定](OUTSIDE-CLICK-DECISION.md)。以下检查按这个最终行为验收：

- [ ] 点击 Codex 正文、输入框或其他软件，底层操作正常，不因全局点击规则统一清空人物气泡、任务/消耗提示或菜单。
- [ ] 打开设置、账户卡片或消费记录时，其周围透明区域保持穿透。
- [ ] 各控件原有关闭按钮、人物点击交互和已有超时规则仍正常；不把这些已有规则误判为全局空白点击关闭。
- [ ] 阅读尚未查看的任务或消耗提示时，在宿主中继续工作不会仅因一次外部点击而丢失提示。

- [ ] API 预警、预算、汇率、记录、图表与高级接口设置正常。

## 显示与宿主输入

- [ ] 任务运行、结束、取消和失败后静置观察，挂件无异常消失或闪跳。
- [ ] 切换应用、最小化/还原、独立桌面/跟随模式切换后位置与层级正确，不抢焦点。
- [ ] Codex 新文字出现、输入和拖选文字时，没有异常白块或光标反复变化。
- [ ] 透明区域与外部拖动继续穿透；按压、拖动、翻转和音效响应可接受。
- [ ] 如果出现不可见，保持现场并按一次 Ctrl+Alt+Shift+F10，记录发生时间。该诊断不弹窗、不截图，也不主动恢复窗口。

## 用量与失败提示

- [ ] API 展示金额，订阅展示本机 token，不混用两种消费提示。
- [ ] 5 小时与每周额度分开显示，各自重置时间正确；过期或无快照有明确说明。
- [ ] 真实订阅账号完成请求后，检查官方快照是否更新；本机 token 未被标成官方剩余额度。
- [ ] 在开启“每轮消耗”时，明确失败、中断或被下一轮替代的未结束任务仍有中性用量提示。
- [ ] 明确重试和流重连不被提前当作最终失败；恢复历史记录不重复弹出提示。
- [ ] 取消与普通失败不播放成功音；未知、待记账金额不显示成零。
- [ ] DeepSeek 峰谷信息只在适用的官方端点显示。

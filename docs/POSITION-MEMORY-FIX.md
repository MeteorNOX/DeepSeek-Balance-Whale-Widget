# 位置记忆修复（本地验证版）

内部版本：`0.3.0+codex.20261004.position-memory`。

启动恢复期间，模式通知曾通过关闭菜单触发吸附，把移动动画的中间坐标反写为正式锚点。缩放也曾在最终坐标确定前保存位置；音量等偏好保存会一并保存临时被小窗口限制的位置。

本版将用户的位置意图与当前绘制坐标分开：启动直接恢复，模式通知和关闭菜单不吸附；视口变化只调整显示。拖动、缩放、显式吸附配置和重置在位置确定后保存，偏好保存不覆盖位置。继续读取既有 v2 边缘距离记录，并在位置提交时立即同步主进程，正常退出再执行落盘刷新。

用户在小窗口中主动拖动或缩放，表示选择新位置；单纯缩小窗口则保留原来的位置意图。模式切换或视口变化中断尚未完成的拖动时恢复上次提交的位置。失效的旧位置记录使用安全的右下默认位置，不能推断已丢失的历史坐标。

验证命令：`node --test tests/*.test.mjs`；Windows 安装好桌面运行时后运行 `node tests/position-memory.mjs`。后者使用隔离数据，检查实际 DOM 坐标、窗口尺寸变化、偏好保存、缩放后重载及拖动后完整进程重启，不只比较存储字符串。

安装使用 `scripts/install-package.ps1`；回滚使用本次安装生成的私有回执及其 `recovery-scripts/rollback-package.ps1`。回滚保留当前设置、资源及新产生的账本；v2 位置格式仍可被旧版读取。

macOS PR #128 的平台实现与署名保留；本次 Windows 验证不代表 macOS 实机验证。此版本未发布到 GitHub。

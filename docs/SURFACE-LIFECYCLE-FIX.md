# 气泡收起与菜单悬停修复

气泡收起时，旧逻辑立即将气泡移出 Windows 原生窗口区域，但子元素的延迟淡出尚未结束，造成直线裁边。菜单按钮则在鼠标离开人物不透明像素时立即隐藏，使人物与按钮之间的透明缝隙成为无法稳定通过的路径。

## 修复行为

- Windows 原生区域根据气泡、菜单和按钮的实际动画生命周期保留绘制边界。关闭动画完成或取消后重新计算当前状态，不用固定延时猜测，也不由旧关闭回调删除重新打开的区域。
- 绘制区域和点击命中分别处理。正在淡出的气泡、菜单、按钮不再接受点击；透明区域继续穿透到底层软件。
- 人物不透明像素仍用于首次唤出按钮。按钮出现后，人物和按钮之间的有限范围用于保留悬停；退出后短暂延迟隐藏，重新进入取消隐藏。菜单打开时保留按钮，“隐藏菜单按钮”偏好优先。
- 悬停保留范围不会加入点击命中区域，不恢复已经撤除的全局空白点击关闭功能。

## 验证重点

Windows 应检查关闭动画中途的实际原生窗口区域和屏幕像素，不能只检查动画结束后的页面截图。还需覆盖关闭后快速重开、菜单缓慢和快速跨越透明缝隙、已关闭区域穿透、隐藏按钮偏好及模式切换。单元测试覆盖延迟隐藏取消和交互状态规则；真实 Electron 测试覆盖动画与窗口区域的组合。

macOS 保留 [PR #128](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/pull/128) 的平台实现和来源；Windows 原生区域逻辑继续受平台判断保护。公共菜单交互有所更新，Mac 实机验证仍需单独完成。

本次 Windows 验证：238 项单元测试通过；16 次真实 `GetWindowRgn`/`GetRegionData` 采样覆盖关闭中途和快速重开；慢速、快速（含翻转后的角色）跨越透明缝隙能打开菜单，`WindowFromPoint` 确认缝隙穿透。隔离测试窗口上的屏幕图确认气泡完整淡出。现有 B 版 Electron 审计的角色、音效、设置、模式切换、拖动与关闭流程均通过。

专项截图使用临时置顶的隔离测试窗口，验证的是动画裁剪，不作为日常跟随层级或长期稳定性的证明。旧 `scripts/smoke-desktop.mjs` 在默认概览页查找隐藏设置页的“角色”文本，仍不适配现有 B 版菜单；该测试和布局代码与修复前相同。本次整体界面验收使用已适配 B 版的 `tests/desktop-audit-smoke.mjs`。

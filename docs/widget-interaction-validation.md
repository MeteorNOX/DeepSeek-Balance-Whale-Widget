# 前端交互修复：验证与回滚

这组修改针对 #188 的到期泡泡、#179 的重复挂载组字守卫、#108 的屏名保存、#91 的菜单出屏、#79 的关闭菜单点击穿透、#55 的自由轴恢复，以及 #158 的配置加载前音频请求。#108 的共享台词池不在本次范围内。

## 无需安装插件的自动验证

在仓库目录运行：

```sh
node --test tests/*.test.mjs
node tools/z-layer-audit.mjs assets/whale-widget.js
node --check assets/whale-widget.js
node --check lib/index.js
node tools/ci-audit.mjs --no-pack
node tools/ci-audit-selftest.mjs
node tools/check-dead-settings.mjs
```

交互测试从实际 `assets/whale-widget.js` 提取函数，用内存中的 DOM、时钟、事件和网络替身执行；不会加载 DSH、播放声音、安装插件或读写浏览器/DSH 的真实配置。测试覆盖过期但仍持有计时器句柄、续时与常驻等待、组字中的重复挂载、编辑器打开到保存的名称与权重往返、菜单边界、关闭菜单的指针序列、位置的自由/锚定轴与旧格式兼容，以及已保存静音设置的加载门。

## 在获准的测试环境中复验

本次未在本机安装或替换插件，也未用 Android、Electron、微软拼音或 IDM 完成实机验证。以下步骤供维护者在已有的专用测试环境中执行：

| 场景 | 操作 | 预期 |
|---|---|---|
| 泡泡到期 | 打开5秒泡泡，隐藏页面超过5秒再恢复 | 到期泡泡收起；刚续时泡泡不提前关闭；常驻提问泡泡保持 |
| 组字 | 微软拼音连续输入，同时触发会重复登记的浮层/节点 | composition结束前不挂新body节点；输入法不上屏、不跳光标 |
| 屏名保存 | 用具名普通屏及具名A/B屏配置打开编辑器，改文本后保存再重开 | 屏名、choice名称、候选名称和权重保留；模块内容保存 |
| 顶部菜单 | 把鲸鱼拖到顶部，打开菜单；缩小视口 | 菜单翻向可用空间、留在视口内；过高时可滚动，所有控件可访问 |
| 关闭菜单 | 菜单打开时点击下方页面按钮，再独立点击该按钮 | 第一次只关闭菜单；第二次正常触发按钮；键盘激活不被吞掉 |
| 位置恢复 | 分别保存两轴自由、单轴自由及两轴吸附的位置后刷新 | 位置及自由轴状态恢复，旧v2配置仍可读；缩放窗口时离边距离保持 |
| 静音启动 | 保存音效关闭，刷新并查看网络；再打开音效 | 配置读回前不预热音频，已静音时没有预热请求；重新开启后恢复当前音效组预热 |

菜单布局自动测试验证的是坐标与边界计算，不能替代真实浏览器的字体度量、动画和触摸事件验证。#159 椭圆内多行文字布局没有在本次修改：需要独立视觉验证，不能用缩字号掩盖溢出。#158 仅修复加载顺序；开启音效后的媒体请求仍可能被下载管理器接管，既有站点排除说明继续适用。#197 多窗口重复音效、#187 音频硬件唤醒和 #195 的系统泡泡状态修复也不在本提交范围内。

## 生效与回滚

这组修改只改变前端运行文件。维护者在获准的测试副本更新该文件后，按 README 的方式硬刷新页面使宿主重新读取资产；无需修改版本号或运行时配置。仓库中的测试和文档不在运行时执行。

源码回滚用 `git revert <本组修改的提交号>`，重新运行以上门禁；测试副本恢复上一版前端资产后硬刷新。不要清空账本、密钥、角色或其他配置来回滚。

位置仍使用 `localStorage['dshw-pos']` 的v2格式，仅增加 `freeH`、`freeV` 和 `flip`。旧客户端忽略这些附加字段，仍可读取已有锚点与距离；旧客户端再次保存后可能丢掉自由轴元数据。屏名沿用既有 `name` 字段，不升级泡泡配置版本；回滚不会主动删名，但旧编辑器再次保存仍可能触发原来的丢名问题。

# 九项修复与验证

内部版本：`0.3.0+codex.20261004.root-fixes`。基于原小鲸鱼 position-memory 版本；保留位置记忆、macOS PR #128 和此前撤除空白点击关闭的决定。

| 问题 | 修复后的行为 |
| --- | --- |
| 音效组不完整、订阅模式跳过完成音 | API 与订阅共用事件音效路径；整组按真实时长播放，遵守开关、事件音量与总音量 |
| 设置保存静默失败、初始化覆盖 | 前端按字段合并、串行保存，检查成功响应；后端按提交字段合并；失败保留待重试内容并显示提示 |
| 新气泡图片失败使旧气泡不过期 | 保存绝对截止时间，失败后恢复剩余时间；恢复窗口复查过期，旧回调不关闭新场景 |
| 编辑器旧缓存使删除内容复活 | 打开读取最新配置，保存比较版本；冲突保留草稿并要求重新打开，不覆盖新配置 |
| 输入法组字时 Enter/Esc 误保存关闭 | 组字期间不处理快捷键 |
| 历史账户账本缺少入口 | 菜单增加匿名历史账户及币种选择；不同账户不合并金额 |
| 极小金额逐次舍入遗漏 | 内部以十进制精度累计已获得的数值，展示才保留两位小数；非零不足 0.01 加小额提示 |
| 峰谷倒计时跨越规则有效期 | 到有效期边界停止推算下一次切换，显示待更新 |
| 并行任务扣费显示成失败对话消费 | 单轮费用与账户期间扣费分离；有完整 token 和价格时显示估算，否则未知；不把账户差额归入某一轮 |

## 金额说明

对话失败不意味着前面已经完成的调用免费。没有 token 记录也不能单独证明免费。本轮 token 估算不是服务商最终账单；同一密钥的期间扣费可能包含其他对话、设备和延迟入账。账户观测日总与本轮估算独立，不能将相互重叠的区间明细相加当作总额。

旧的区间扣费记录在读取时采用新展示口径，原始账本不覆盖。内部不会把两位显示值用于计算；精度上限仍受服务商返回值及数值转换影响，并非任意精度账单保证。

## 手动验证

1. 同时运行两个对话，其中一个失败：失败气泡有状态和匿名对话短码；缺少有效价格时金额未知，另一个对话的账户扣费不记到它名下。
2. 有有效模型价格时，查看本轮估算；不足 0.01 的非零金额显示两位小数并有小额提示。
3. 在小、中、大挂件尺寸查看失败、取消、大金额气泡，文字应在气泡内。
4. 音效选整组，分别在 API 和订阅模式完成任务；核对顺序、音量和开关。关闭音效后不得播放。
5. 调节音量或大小，重启挂件后保留设置和位置；两个编辑器同时修改时，旧编辑器保存应报冲突，不能恢复已删模块。
6. 使用中文输入法确认候选词，Enter/Esc 不误保存或关闭；打开“历史账户账本”检查账户与币种切换。

## 回滚

完整安装自动保存当前程序、数据和本次私有回执。使用交付目录的专用回滚入口，恢复此次安装前的程序，保留当前设置、角色和新增用量记录。源码与验证报告继续保留。旧版不支持的展示能力回滚后不再出现。不要通过删除账本来回滚。

Windows 自动化验证不代表 macOS 实机测试。原始跨平台来源：https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/pull/128 。

## 数据口径

- API 余额以服务商响应为准；观测差额不保证逐请求准确归属。
- 订阅额度来自本机 Codex `token_count.rate_limits` 的窗口快照；5 小时/周按实际窗口分钟数识别。15 分钟未更新或重置时间已过会标为过期。
- 当前登录方式无法识别为 ChatGPT 订阅时，不显示历史订阅窗口。登录信息更新时间晚于快照时也不显示该旧快照。
- 本机近 7 天/滚动 5 小时 token 是独立观测统计，不是官方固定 token 配额。只保留计数，不保留聊天正文、标题或凭据。
- 观测最多扫描近期 256 个文件、128 MiB 数据，超过预算明确显示不完整；读取放在 worker，避免阻塞挂件主进程。
- DeepSeek 当前时段只用于显示，域名需为 `api.deepseek.com`。按 2026-09-28 官方定价页和参考包 2026 节假日清单；2027 及其他未验证时间显示规则需更新，不猜测节假日。

官方规则：<https://api-docs.deepseek.com/quick_start/pricing>

## 本版限制

Windows 可运行本地回归。macOS 保留代码并静态验证，但当前主机不能代替 Apple Silicon/Intel、Spaces、多屏和睡眠唤醒的实机验收。订阅快照使用合成样本验证；没有真实订阅测试样本时不得称为账户端到端已验证。

本地工坊是用户导入/导出的 JSON 媒体包，不是在线市场。包不执行脚本、不包含密钥/账本/私人接口设置。新增短音由程序合成，原媒体许可不变。

# v0.4 功能范围与验证

**For-Codex v0.4.0 发布说明，标签 `codex-v0.4.0`。** 对外附件为 `Codex-v0.4.zip` / `Codex-v0.4-source.zip`，程序版本 `0.4.0`，内部标识 `api-balance-whale`。实际测试与待验证范围分别列在下文。

## 两项最新使用反馈

| 反馈 | 最终行为 |
| --- | --- |
| 并行工作时只有“单轮金额未知”，失去消费金额反馈 | 账户新增扣费独立显示，不要求模型单价；本轮 token、状态和价格估算保留，账户差额不归属某个失败对话。 |
| 连续点击人物时可能点到背后窗口 | 共用稳定交互轮廓和 alpha，保护已接受按压及回弹；原生窗口区域同步保留该有限范围，真正透明区继续穿透。 |

这两项来自近期使用反馈，目前没有独立 GitHub issue，不虚构编号。累计 issue 的完整/子问题/未实现/不适用分类见 [状态表](ISSUE-STATUS-0.4.md)。

## 账户新增通知的具体语义

1. 首次有效采样为通知建立基准，升级前历史不作为新消息追报。正常账户账本仍按既有规则记录。
2. 后续有效正向增量按账户、币种和计量上下文累计，同笔增量只进入一个批次。缓存、失败、过期或被拒绝的乱序样本不制造新通知。
3. 批次保留到实际呈现后确认。已显示标识先存本地，再确认后端；确认失败后可重试。正常存储条件下，刷新不重复显示已经呈现的金额。
4. 提示关闭、页面隐藏或订阅显示模式下暂停 API 账户通知；新增量合并为待显示累计。有已发出的未确认批次时同时保留它，后台不是逐采样的无限长数组。
5. 通常约每 60 秒后台查余额，任务起止/主动刷新也触发查询。通知可在稍后采样才出现，不承诺每轮结束立即取得实际账单。
6. 账户新增提示不播放任务成功音。单轮未知费用保留 token，失败或取消仍可能已消费额度。

该实现保证的是账户观测与通知归属，不提供服务商逐请求账单。当前退款导致的累计值回退或余额回升不冲减旧正消费；充值/退款/消费混合、跨日分摊仍有限制。见 [已知问题](KNOWN-ISSUES-0.4.md)。

## 当前验证结果

| 验证项目 | 当前结果 | 证据适用范围 |
| --- | --- | --- |
| 本次发布源码自动测试 | 重新运行 341 项，全部通过 | 当前 v0.4 的账户、任务、设置、输入、渲染和安装等回归；具体结果以成品报告为准。 |
| 本次独立隐私门禁测试 | 重新运行 9 项，全部通过 | 用合成敏感样本验证打包拒绝逻辑，不代表允许公开本机运行资料。 |
| 先前同一运行实现的原生边缘连击 | 120 次，零泄漏；本次未重跑 | 专用无害 Windows 宿主，6 组各 20 次真实原生输入。 |
| 先前透明区点击对照 | 18 次正常穿透；本次未重跑 | 同一专用宿主；不能为防误点而全屏拦截。 |
| 先前同一运行实现的账户通知端到端 | 5 组通过；本次未重跑 | 真实 Electron 渲染、路由和持久化通知；金额由隔离服务桩提供，未调用真实付费账户。 |

原生连击的六种组合：

| 角色大小 | 方向 | 点击间隔 |
| --- | --- | --- |
| 0.6 | 正常 | 20ms |
| 0.6 | 翻转 | 50ms |
| 1.2 | 正常 | 100ms |
| 1.2 | 翻转 | 20ms |
| 2.0 | 正常 | 50ms |
| 2.0 | 翻转 | 100ms |

63 个释放时当前动画 alpha 不命中的事件由稳定轮廓保护，原生区域包含目标点。它证明这组测试有效覆盖了回弹间隙，不等于所有设备、所有坐标和所有间隔的穷举。

账户通知五组场景：

| 场景 | 验证结果 |
| --- | --- |
| 未配置单价、两个任务并行产生 0.25 新增 | 显示账户金额及并行标识，实际呈现/本地记录之后才确认。 |
| 同一采样重复读取，两个任务相继结束 | 不重报同笔 0.25。 |
| 再新增 0.10，模拟确认失败并刷新页面 | 新增独立成批；刷新只重试确认，不重放金额。 |
| 关闭消费提示期间新增 0.20，再启用 | 关闭时不消费待显示批次，恢复后显示一次。 |
| 订阅模式期间新增 0.10，再回到 API 模式 | API 待显示金额保留，回切后显示一次。 |

这些为合成金额，不是开发者真实账单。账户气泡的实机渲染同时检查文字仍在椭圆内部，账户新增不触发任务成功音。

## 较早基线与尚未验收

52 个通用气泡布局场景和位置重启验证来自较早相关实现，继续作为基线依据，**不是本版重新跑出的 52 项**。自动测试、原生输入和合成服务端到端仍不替代真实订阅账号、真实服务商账单、Mac、其它输入硬件、多屏和长期观察。

成品哈希、版本、文件范围和解压核验记录在发行目录的 `release-manifest.json`、`verification-report.json`。测试过程的原始日志、现场截图和本机回执不放入公开安装包。

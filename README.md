## 先安装，再开始使用

1. 准备支持插件的 Codex 桌面应用、可用的插件注册 CLI 及 **Node.js 24+（含 npm）**；安装器会检查所需命令。
2. 完整解压 `Codex-v0.4.1.zip` 到固定目录；不要直接在 ZIP 内运行。
3. Windows 双击 `安装插件.cmd`。首次安装需要联网下载 Electron，此包不是包含运行时的离线 EXE。
4. 按安装器结果确认成功，打开 Codex。需要在聊天中使用新版技能和工具时，新建聊天加载。
5. 打开鲸鱼菜单，在顶部选择 **API 余额** 或 **Codex 订阅**。菜单分为“概览 / 用量 / 设置”。

安装器备份现有插件和数据、注册本地插件并配置自动跟随。此前主动暂停过挂件时，保留暂停意图；需要恢复时主动打开挂件，或明确使用安装脚本的 `-Resume` 选项。

可先做 Windows 安装预检：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-package.ps1 -CheckOnly
```

macOS 使用新的独立目录，保留旧版本，运行 `安装 Mac 自动跟随.command`；还需 Xcode Command Line Tools 提供 Swift。该脚本安装桌面组件与 LaunchAgent，**不自动完成 Codex 插件市场的技能/MCP 注册**。详见 [macOS 安装与回滚](docs/MACOS.md)。

## 能做什么

| 功能 | 使用方式与边界 |
| --- | --- |
| 账户新增消费 | 有效余额/累计用量采样发现新增扣费后显示金额，不依赖模型价格、不归属某个对话；同笔增量去重，关闭提示期间合并待显示累计。 |
| API 余额与账本 | 自动读取可用的 Codex API 配置；支持兼容账单、兼容密钥额度、DeepSeek 原生余额和自定义同源 JSON 余额接口。接口类型和换算单位应按服务商文档设置。 |
| 任务结束提示 | 完成、取消和明确失败显示相应状态；保留本轮 token。配置有效模型价格后显示费用估算，证据不足时显示本轮 token，费用未单独确认；账户新增扣费另有金额气泡。 |
| Codex 订阅快照 | 分别显示 5 小时和周窗口、重置时间与过期状态；没有可靠快照时说明不可用，不把本机 token 当剩余额度。 |
| 历史账户 | 按匿名账户与币种查看旧账本；换密钥后不需要恢复失效密钥才能查看旧记录。 |
| 跟随与位置 | 跟随 Codex 或独立停留桌面；拖动、缩放、吸附、翻转和位置记忆。窗口暂时缩小不会覆盖用户记忆位置。 |
| 角色、气泡与声音 | 原有角色/动图、模块气泡、图片和音效组；完成音效组依次播放完整片段，独立事件音量和静音。 |
| 手感与本地工坊 | 三种按压/回弹手感、原创合成短音；导入/导出角色、气泡图、音频与音效组 JSON 包。工坊是本地素材交换，不是在线市场。 |
| 币种与汇率 | 显示换算使用公开 USD/CNY 参考汇率；缓存、每日北京时间 00:15 检查、唤醒补查与主动刷新。灰色感叹号按钮展开说明，账本原币种不变。 |
| DeepSeek 峰谷提示 | 仅直接连接官方 API 端点且规则在有效期内时展示；不套用到中转站，不修改账单或模型价格。 |

已有 API 地址、环境变量名和本机路径在设置中默认隐藏；留空保留原值，填写才修改。密钥字段填写的是**环境变量名**，例如 `MY_API_KEY`，不要把密钥粘进去。更换 API 域名时必须提供属于该服务的凭据，避免跨域复用。

## 账户新增消费、本轮 token 与估算有什么区别

账户余额差额只能说明同一密钥在一段时间内发生了扣费，可能包含并行聊天、其他设备及延迟入账，不能据此认定某个对话花了多少钱。

- **账户新增消耗**：自通知基准以来尚未提示的账户新增扣费，有有效采样即可显示，不要求模型单价。它可能包含并行任务、其他设备或延迟入账。
- **本轮估算**：本轮 token 与用户配置的模型价格计算的结果；不会再次叠加到账户总额。
- **单轮费用未单独确认**：保留本轮 token；账户新增扣费照常独立报告。失败或取消不等于免费，前面已发生的调用仍可能计费。

第一次有效样本只建立通知基准，不把升级前的历史消费整笔弹出。此后通常约每 60 秒后台采样，任务开始、结束或用户刷新也可触发查询；服务商延迟入账还会增加等待时间，所以金额气泡不保证每轮结束立即出现。

气泡实际呈现后才确认批次；重复采样、多个任务结束或确认重试不重复分配同一增量。关闭气泡总开关/“每轮消耗提示”、隐藏页面或切到订阅模式时，API 账户通知暂停展示，新增量合并成待显示累计；重新启用后再显示。后台最多保留一个已发出的未确认批次和一个累计，不制造无限长提示队列。账户金额提示本身不播放任务成功音。

内部以高精度十进制累计，界面保留两位小数；小于 0.01 的正金额另有简短提示，显示成 0.00 不意味着没有累计。旧版错误归属为“本轮”的共享密钥期间金额，在读取时改为账户区间说明，不改写原始历史。

停机或跨午夜期间的差额在恢复观测后归入再次观测日，无法凭余额接口精确拆回每一天。退款、充值与消费同时发生时，余额净变化也不等于完整流水；当前对累计用量回退或余额回升不冲减已累计正消费，因此不是退款后的净额账本。实际计费以服务商账单为准。详见 [已知限制](docs/KNOWN-ISSUES-0.4.md)。

## 为什么不做全局空白点击关闭

[Issue #177](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/issues/177) 的便利性诉求合理，但挂件覆盖在工作软件上，底层点击可能只是输入、拖选或切换任务，并不代表已读完提示。统一清空容易误关未读气泡，且主菜单、子面板、账户卡片的关闭边界不同；跨平台全局监听还增加生命周期维护成本。

因此继续保留明确关闭按钮、人物点击和各类提示自身的超时规则；透明区域保持点击穿透。这是主动的产品取舍，不是技术无法实现，也不表示该 issue 已解决。见 [交互决定](docs/OUTSIDE-CLICK-DECISION.md)。

## 如何验证生效

安装后先检查状态中的版本为 `0.4.1`，再完成 [用户验收清单](docs/TEST-CHECKLIST-0.4.md)。重点检查无需单价的账户新增金额、重复刷新不重报、关闭再启用后的累计提示，以及角色边缘连击和透明区穿透；再检查拖动/缩放后重启、最小化恢复、两种额度窗口、长气泡及保存失败提示。

挂件暂时不可见时，可从托盘选择“恢复显示小鲸鱼”，或使用 Windows `Ctrl+Alt+W` / Mac `Cmd+Option+W`。Windows `Ctrl+Alt+Shift+F10` 可保存诊断现场。退出挂件只停止观察，不会取消 Codex 模型调用。诊断结果可能含本机运行信息，公开反馈前需脱敏。

## 如何回滚

Windows 双击 `回滚本次安装.cmd`，也可先检查：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\rollback-package.ps1 -CheckOnly
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\rollback-package.ps1
```

回滚使用本次安装生成的私有回执，恢复旧代码和启动任务，保留最新设置、素材与账本；操作前保存当前状态。新装没有旧版本时撤回本次安装。请保留安装备份和回执；缺少有效回执时不会猜测备份位置。macOS 使用 `回滚 Mac 更新.command`，具体行为见 [平台文档](docs/MACOS.md)。

## 数据、兼容性与来源

数据默认放在 `~/.codex/whale-widget`；可由 `CODEX_HOME` / `WHALE_HOME` 调整。公开包不包含个人配置、凭据、账户账本、聊天记录、原始日志、截图录屏或私有回滚回执。`runtime.json` 含本地 IPC 令牌，不应公开；本地工坊导出也请确认自定义素材没有私人内容。

订阅观察读取本机会话中的用量和额度事件，没有新增登录流程，也不发送聊天内容。本机 token 统计可能涵盖多账号和提供商；扫描有资源上限，达到上限时标明不完整。

持续保留 [macOS PR #128](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/pull/128)，作者 [1llysviel](https://github.com/1llysviel)，包括平台探针、LaunchAgent、透明浮窗和 Unix socket 路径。本轮没有 Mac 实机环境，不将 Windows 测试等同于 Mac 通过。更多限制见 [已知问题](docs/KNOWN-ISSUES-0.4.md)。

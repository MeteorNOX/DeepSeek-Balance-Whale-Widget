# 桌面端开关 E2E

环境：macOS、DeepSeek Harness Desktop 0.2.1-rc.2，本地 link 安装，实际
`dsh-app://app/` 页面。通过原生界面操作开关、切换页面和退出重开，使用同一页面的
Console 检查实例与资源。验证日期：2026-10-23。

## 开关与导航

| 操作 | 结果 |
| --- | --- |
| 在 Plugins 开启，停留在原页 | 挂件出现；没有聊天输入框也能初始化 |
| 在 Plugins 关闭后重新开启 | 挂件消失后重新出现，无需进入聊天或刷新 |
| 开启后进入 Shell 子设置 | 挂件保持可见 |
| 从子设置切回聊天 | 挂件保持可见，始终只有一个实例 |
| 关闭后留在聊天页 | 挂件、脚本和自有样式消失，后续 DOM 变化不会使其复活 |

开关和导航期间 `performance.timeOrigin` 保持不变。关闭后的实例
`active === false`，`resources()` 记录为：

```json
{"timers":0,"observers":0,"listeners":0,"nodes":0,"audioContexts":0}
```

关闭后分别在 57 秒和 79 秒检查，挂件和脚本数量均为 0，页面没有重载。

## 冷启动

| 操作 | 结果 |
| --- | --- |
| 开启插件，完全退出应用后重开 | 挂件自动出现，只有一个挂件和一个脚本 |
| 关闭插件，完全退出应用后重开 | 挂件不出现，Plugins 开关保持关闭 |
| 关闭状态冷启动后，在 Plugins 开启 | 当前页直接显示挂件，只有一个挂件和一个脚本 |

最后一次冷启动后 169 秒检查，页面仍为同一个实例。Plugins 页面中没有聊天输入框，
挂件可见、生命周期为 active。

## 复验

1. 在 Plugins 页开启挂件，不切回聊天，确认右下角可见。
2. 保留 `window.__dshWhaleLifecycle` 引用，关闭后检查其 `active` 和 `resources()`；
   检查 `.dshwv-root`、`script[data-dsh-whale-widget]` 与自有样式均已移除。
3. 反复开关并切换设置、聊天页面，核对 `performance.timeOrigin` 不变、没有重复实例。
4. 分别在开启和关闭状态完全退出应用，重开后检查状态；关闭状态下再从 Plugins 开启。
5. 关闭后停留至少一分钟，确认挂件没有被 DOM 自恢复逻辑重新挂载。

`node --test tests/*.test.*` 另外覆盖脚本迟到、旧实例回调、DOM 尚未就绪时取消启动、
在途请求取消和初始化失败。启动单测使用简化渲染器隔离启动条件；实际显示由上述桌面 E2E 验证。
